# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/expogacha/contracts/security/advisories/new).
Do not open a public issue for anything that could put funds or NFTs at risk.

A useful report includes the affected contract and version (`src/` for v3.2, `v31/src/` for v3.1), the impact, and a
Foundry test or the steps that reproduce it.
